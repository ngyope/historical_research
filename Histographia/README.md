# Histographia

Histographia は、スコットランド史の出来事と史料を相互にたどりながら学べるインタラクティブ閲覧ツールです。章どうしのつながりを追うだけでなく、各章に紐づいた史料や、ひとつの史料から参照される複数の章も行き来できます。

現行版のテーマは `Scottish Experience 1286-1294` です。

## できること

- 章のネットワークをたどって出来事の流れを追う
- ノードにカーソルを合わせて、章の題名・日付・導入をその場で確かめる
- マウスホイールで地図を拡大・縮小し、「旅の全体を見る」で行程を一望する
- 各章に対応する史料を読む
- ひとつの史料が関わる複数の章を見比べる
- たどってきた履歴を `Codex` の `旅路` タブで振り返る
- BGM と効果音をオン・オフする

## 起動方法

ビルドやサーバー起動は不要です。次のどちらかで利用できます。

## 画面の見方

### 開始画面

- `探検ルートを選ぶ`: 最初に入る章のまとまりを選びます
- `この旅路を始める`: 選択したルートから閲覧を開始します
- 右側または下部のプレビュー: 選択中ルートの概要を確認できます

### メイン画面

- 中央のマップ: 章や史料の関係を可視化するネットワークです。ノードにカーソルを合わせると題名・日付・導入・状態（未踏／訪問済み）がツールチップで表示されます
- マップ左上の操作ボタン: 章ネットワーク表示では「旅の全体を見る」「現在地へ」、史料表示中は「章ネットワークへ戻る」等のモード復帰ボタンが表示されます
- `Codex`: 詳細表示パネルです。`章` `史料` `旅路` の3タブを持ちます

### ヘッダー

- `音をオン/オフ` ボタン: BGM と効果音を切り替えます
- `探検準備へ`: 開始画面に戻ります

## 基本的な使い方

### 1. 旅を始める

開始画面でルートを選び、`この旅路を始める` を押します。

### 2. 章を開く

マップ上の章ノードを選ぶと、その章が現在地になります。`Codex` の内容もその章に合わせて更新されます。現在地のノードには紐づく史料の件数バッジが表示され、もう一度クリックすると章→史料の表示に切り替わります。

### 3. 章の本文を読む

`Codex` の `章` タブでは、次の内容を確認できます。

- 章タイトル
- 概要（本文）
- 詳細（補足説明、あるときのみ）
- 「史料を読む」ボタン（`史料` タブへ）
- 次に踏み込める章の一覧（✓ は訪問済み）

### 4. 史料を読む

`Codex` の `史料` タブでは、現在の章に紐づく史料を読めます。史料ごとに以下が表示されます。

- 史料名
- 史料本文
- 出典表記

### 5. 章と史料を行き来する

このツールは、閲覧中の状態に応じて大きく次の 3 通りの見方を切り替えます。

- 章から章へたどる表示
- ひとつの章に関連する史料を見る表示
- ひとつの史料に関わる章を見る表示

そのため、章を起点に史料へ進み、さらにその史料を共有する別の章へ移る、といった読み方ができます。

### 6. 履歴を振り返る

たどった順路は `Codex` の `旅路` タブで確認できます。踏査の進み具合と発見した史料の件数もここに表示されます。

### 7. 詳細表示を広げる

`Codex` 右上の `全画面` を押すと、詳細パネルを広く表示できます。`✕` で閉じることもできます。

## 音声について

- 音声再生には `Assets/lib/howler.min.js` を使用しています
- ブラウザによっては、自動再生が制限されることがあります
- 音が出ないときは、一度画面上で操作してから `音をオン/オフ` を切り替えてください

## よくある確認事項

### 音が出ない

- 画面を一度クリックまたはタップした後に音声ボタンを切り替えてください
- ブラウザ側でタブがミュートされていないか確認してください
